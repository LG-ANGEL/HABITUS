# Habitus · by VIRTUS ARS

Rastreador de hábitos como app Android (WebView). La interfaz está en `app/src/main/assets/index.html`.

## Generar el APK con GitHub
1. Crea un repositorio y sube todo este proyecto a la rama `main`.
2. Ve a la pestaña **Actions**, abre **Build APK** y espera a que termine (o toca **Run workflow**).
3. Descarga el artefacto **Habitus-APK**, descomprímelo e instala `app-debug.apk`.
